# 七政四余视图 v1.0 设计文档「同一天空，三个视角」

> 2026-09 定稿。背景：v0.8/v0.9 双栏（左命理星盘 + 右 CSS3D 太阳系）经用户截图评审后，
> 确认存在架构性问题，本方案为重构蓝图（P0–P3）。先设计后动手。

## 一、评审结论（四问）

1. **信息不直观**：左盘（黄经→宫宿）与右图（日心轨道）共享同一组黄经，却无任何可见共享参照系
   （无 0° 基准、无黄道刻度、无方向标记），两图"各说各话"，映射关系藏在代码里。
2. **用处有限且传递错误天文观**：四余（罗睺=月交升点、计都=月交降点、月孛=月远地点、紫气=历法虚点）
   是黄道圈上的特殊点，不是天体；v0.8 却给它们各画虚构轨道+球体+虚构周期。命理价值上 3D 图
   对命宫/化曜/口径差零贡献。
3. **天文-命理联系不优雅**：联系只有共享 `curLon()` 时间轴；无共享刻度、无联动线、命宫未同时在两图标出。
4. **3D 架构是残缺伪 3D**：只有方位角 rotateY（无俯仰无缩放）；标签放在 3D 平面内 →
   随视角压扁/遮挡/脱锚（紫气悬空、计都不可见）；近侧行星挡太阳无深度提示；无任何参照刻度。

## 二、核心命题

**一张图说清三件事：星在黄道上哪里（黄经盘）、星在真实轨道哪里（日心图）、命理坐标怎么读（命宫/化曜/口径）。**
三者共享同一根黄经轴（0°=春分方向）与同一根时间轴。

## 四、组件细节

### ① 左盘 黄道黄经盘（SVG，重构）

- 保留：28 宿度环（r 137–146）、十二宫带（r 150–184）、中心命宫盒、命宫金色扇区。
- 星曜游标：七政（圆点）+ 四余（菱形♦）统一画在黄经环 r≈114，按黄经排列；不做三圈错落。
- 盘外读数环（viewBox 380→440，标签区 r≈192–222）：
  - 弯标签 = 星名 + 宫名 单行，按黄经角度排序；
  - 稠密时径向叠 3 层（贪心槽位算法，保证两两不重叠）；
  - 每条标签一条细引导线连向星体。
- 次级信息（宿度数、入命宫）只在悬停时经 ③ 信息条显示，盘面不放。
- 紫气多口径：删除环内 5 圆点，改在 ④ 口径对照条（5 行：口径名 + 度数 + 选中态）。

### ② 右图 日心轨道图（CSS 3D，重构）

- 只画七政：太阳 + 六行星（月嵌地球旁）；轨道半径用平方根压缩，标注"示意比例"；周期真实。
- 四余画在黄道圈（金色/银灰环）：罗睺♦橙、计都♦蓝、月孛◇紫、紫气◇粉；**删除全部四余伪轨道**。
- 黄道刻度环：0°（春分方向锚点）、30°…330° + 十二星座名 + 二十八宿主刻度 ← 与左盘共享黄经轴。
- 命宫金弧：黄道圈上命宫初度→末度的金弧 + 命度刻度线。
- 相机：yaw 0–360°、pitch 15–85°（默认 60°）、滚轮缩放；预设按钮（俯视/示意/侧视/复位）。
- 屏幕空间标签层：JS 手写透视投影（~20 行），标签永远水平、深色胶囊、45° 引导线，不脱锚不叠加。
- 深度提示：太阳光晕缩小；经过太阳前方的行星加细描边；近侧行星标签优先显示。
- 联动：左右图悬停同一星双图高亮。

### ③ 中央信息条
`土星 · 黄经 294.0° · 丑宫斗宿 20.6° · 化禄`；悬停/选中出现；Python 数据不全时显示已有并注明。

### ④ 底部控制器
- 播放器：▶ 运转 / ⏺ 定格实际 / 相对日数滑条（"运行 365 天/3 年"）。
- 紫气口径对照：5 行按钮（果老 1900 白羊初度 59.2° …），点击切换，盘面与黄道圈紫气点即时跳位。

## 六、不做的事

- 不引入 three.js/WebGL（手写单文件插件、无打包器，CSS 3D + 投影标签层足够）。
- 不做专业天象演示（星等/星座连线等，Stellarium 范畴，不服务命理）。
- 不把化曜/神煞硬塞盘面（信息分层，框内只放星位与刻度）。
