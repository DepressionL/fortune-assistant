## 1. 八宫卦序完整表（含世爻、应爻位置）

### 1.1 世爻 / 应爻 位置规则

六爻卦六爻自下而上，记为 初爻(1)、二爻(2)、三爻(3)、四爻(4)、五爻(5)、上爻(6)。
每宫八卦按「本宫 → 一世 → 二世 → 三世 → 四世 → 五世 → 游魂 → 归魂」排列，世爻位置随卦次递进。世爻与应爻**恒隔两爻**（即「世初应四、世二应五、世三应六、世四应一、世五应二、世上应三」之三格对位）；下表直接给出每卦具体世应爻位，避免数位歧义。

### 2.2 八纯卦六爻地支

阳卦地支顺行（子→寅→辰→午→申→戌），阴卦地支逆行；各卦起支不同。每一卦皆以内卦三爻、外卦三爻排列。

|---|---|---|---|---|---|---|---|
| 乾（阳） | 子 | 寅 | 辰 | 午 | 申 | 戌 | 子寅辰午申戌 |
| 坤（阴） | 未 | 巳 | 卯 | 丑 | 亥 | 酉 | 未巳卯丑亥酉 |
| 震（阳） | 子 | 寅 | 辰 | 午 | 申 | 戌 | 子寅辰午申戌 |
| 巽（阴） | 丑 | 亥 | 酉 | 未 | 巳 | 卯 | 丑亥酉未巳卯 |
| 坎（阳） | 寅 | 辰 | 午 | 申 | 戌 | 子 | 寅辰午申戌子 |
| 离（阴） | 卯 | 丑 | 亥 | 酉 | 未 | 巳 | 卯丑亥酉未巳 |

> 助记歌（纳甲歌）：乾金甲子外壬午，坎水戊寅外戊申；艮土丙辰外丙戌，震木庚子外庚午；巽木辛丑外辛未，离火己卯外己酉；坤土乙未外癸丑，兑金丁巳外丁亥。
> 规律：阳卦地支顺行（自初爻起）、阴卦地支逆行，且每卦地支链内相邻两爻皆隔一位（六冲：子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲）。内卦三爻与外卦三爻天干不同（乾甲/壬、坤乙/癸），其余六卦内外卦天干相同。

### 2.3 其余 56 卦如何组合地支（复用地支）

64 卦皆由「上卦 + 下卦」组成，装卦时**上下卦各自套用其八纯卦的地支**，不做改变，仅作上下组合：

- 下卦：取其八纯卦的「内卦三爻」（初、二、三爻）地支。
- 上卦：取其八纯卦的「外卦三爻」（四、五、上爻）地支。

即：任一卦的六爻地支 = 上卦之纯卦外卦三支 + 下卦之纯卦内卦三支。天干同理（上卦用外卦干、下卦用内卦干）。

例（天风姤 = 上乾 / 下巽）：下卦巽用内卦三爻丑、亥、酉，上卦乾用外卦三爻午、申、戌，故姤卦地支为 初丑、二亥、三酉、四午、五申、上戌。（巽属木，姤属乾宫金。）

## 3. 六亲定法

以「卦宫五行」为我（即该宫属金/木/水/火/土），以「爻支五行」为他，按五行生克定六亲：

| 他（爻支五行）相对 我（卦宫五行） | 六亲 |
|---|---|
| 生我者 | 父母 |
| 我生者 | 子孙 |
| 克我者 | 官鬼 |
| 我克者 | 妻财 |
| 与我同类（比和） | 兄弟 |

五行相生：木→火→土→金→水→木。五行相克：木→土→水→火→金→木。

判断口诀（以宫我为基准）：
- 爻支生宫 → 父母爻（生我者父母，主文书、长辈、房宅。）
- 宫生爻支 → 子孙爻（我生者子孙，主晚辈、福神、财源。）
- 爻支克宫 → 官鬼爻（克我者官鬼，主官非、疾病、丈夫、鬼神。）
- 宫克爻支 → 妻财爻（我克者妻财，主钱财、妻妾。）
- 爻支与宫同五行 → 兄弟爻（比和者兄弟，主同辈、竞争、劫财。）

## 4. 六神表

六神（六兽）：青龙、朱雀、勾陈、螣蛇、白虎、玄武。以一卦六爻自初爻至上爻顺排六兽，起首由**日干**决定：

| 日干 | 初爻六神（起首） | 次序 |
|---|---|---|
| 甲乙 | 青龙 | 青龙→朱雀→勾陈→螣蛇→白虎→玄武 |
| 丙丁 | 朱雀 | 朱雀→勾陈→螣蛇→白虎→玄武→青龙 |
| 戊 | 勾陈 | 勾陈→螣蛇→白虎→玄武→青龙→朱雀 |
| 己 | 螣蛇 | 螣蛇→白虎→玄武→青龙→朱雀→勾陈 |
| 庚辛 | 白虎 | 白虎→玄武→青龙→朱雀→勾陈→螣蛇 |

## 5. 旬空表（六甲旬空）

以六十甲子分六旬，每旬（十日）有二支为空亡（不入卦中气数，属虚空无力）：

| 旬 | 干支范围（10 组） | 空亡地支 |
|---|---|---|
| 甲子旬 | 甲子…癸酉 | 戌、亥 |
| 甲戌旬 | 甲戌…癸未 | 申、酉 |
| 甲申旬 | 甲申…癸巳 | 午、未 |
| 甲午旬 | 甲午…癸卯 | 辰、巳 |
| 甲辰旬 | 甲辰…癸丑 | 寅、卯 |
| 甲寅旬 | 甲寅…癸亥 | 子、丑 |

> 记忆法：每旬旬首为「甲X」，该旬空亡的地支 = 该旬配地支之后两位（如甲子旬：子之后为丑寅……到戌亥恰好是旬首前后配对所余之支）。六十甲子中每旬末尾的旬支与旬首配对后，余下的两个地支即空亡。

## 6. 起卦法（三枚铜钱）

以三枚铜钱（或硬币）掷六次，自下而上得六爻。以「字」为阴面、「背（花）」为阳面计分：

### 6.1 背(阳)=3、字(阴)=2 的通行计分

| 铜钱组合 | 计分 | 爻象 | 名称 | 是否动爻 |
|---|---|---|---|---|
| 二背一字 | 3+3+2 = 8 | 阴爻（— —） | 少阴（拆） | 静爻 |
| 一背二字 | 3+2+2 = 7 | 阳爻（——） | 少阳（单） | 静爻 |
| 三背 | 3+3+3 = 9 | 阳爻（——）动 | 老阳（重） | 动爻 |
| 三字 | 2+2+2 = 6 | 阴爻（— —）动 | 老阴（交） | 动爻 |

即：**7 少阳（单）、8 少阴（拆）、9 老阳（重，动）、6 老阴（交，动）**。动爻老阳（9）变阴、老阴（6）变阳，其余静爻不变；由本卦各爻变化得「变卦（之卦）」。
装卦时记：单「/」、拆「//」（或有作─ ─）、重「O」、交「X」。

### 6.2 关于「背为阳 / 背为阴」两种约定的分歧

- **主流（多数教材）：背为阳、字为阴。「三背」= 3+3+3 = 9 = 老阳；「三字」= 6 = 老阴。** 即背(花)的个数多者为阳爻。
- 另一约定：**背为阴、字为阳**（即把字面视为阳、分值相反：得 7/8 时阴阳互反）。此说以「字面」为阳，多见于把「有字一面朝上=阳」的直觉约定。两说在「老阳/老阴」的取值上恰好相反，断爻时必先定准所用约定。
- **本表采用主流（背=阳、背=3）约定**，建议程序实现时默认此约定，并提供约定开关。

## 7. 断卦核心概念简表

| 概念 | 要点 |
|---|---|
| 用神 | 所测之事对应的爻。占财取妻财爻、占父母取父母爻、占官取官鬼爻、占子女取子孙爻、占兄弟取兄弟爻；占自身取世爻。 |
| 原神 | 生用神之爻（用神的「父母」）。用神受生则吉。 |
| 忌神 | 克用神之爻。克用神则凶。 |
| 仇神 | 克原神、又生忌神之爻（助忌制原，恶）。 |
| 月建 | 起卦之月的地支。爻值月建或与月建同气则旺相；月建克爻则爻衰。 |
| 日辰 | 起卦之日的地支。爻值日辰（临日）者有力；日辰生克亦影响爻之旺衰。 |
| 旬空 | 值旬空之爻暂时虚而无力（见第5节）；出旬（过该旬）或逢冲填实后恢复作用。 |
| 动变 | 老阳（9）、老阴（6）为动爻。动爻才生克其它爻；动爻化出之变爻（之卦对应爻）可再看其生克。安静卦动爻少、大象以静为本。 |

> 断卦取象为大纲；实际判断还需结合卦身、应期、六神象意、用神旺衰等，本表为入门要点。
