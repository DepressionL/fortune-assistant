## 1. 命宫、身宫安法 与 十二宫顺排顺序

### 1.1 口诀原文（安身命宫）

《紫微斗数全书》安身命星诀：

> **「寅起正月，顺数生月，逆数生时，为命宫；从该宫起子时，顺数生时，为身宫。」**

更完整表述（王亭之《中州派讲义》/常见安星诀）：

> 安命宫：**自寅宫起，顺数至生月**，得「月宫」；**再从月宫起子时，逆数至生时**，所落之宫即**命宫**。
> 安身宫：**自寅宫起，顺数至生月**，得「月宫」；**再从月宫起子时，顺数至生时**，所落之宫即**身宫**。

### 1.2 推算步骤（Python 可落地）

统一采用地支柱序（下同全文 `BR`）：`BR = ["子","丑","寅","卯","辰","巳","午","未","申","酉","戌","亥"]`，索引 `0=子, 1=丑, 2=寅, 3=卯, …, 11=亥`。

- 生月 `m`（正月=1 … 腊月=12），生时 `h`（子时=0, 丑=1, …, 亥=11）。
- **月宫**（自寅起顺数生月）：`yue = (2 + (m-1)) % 12`　# 寅索引=2
- **命宫**（自月宫起子时，逆数生时）：`ming = (yue - h) % 12`
- **身宫**（自月宫起子时，顺数生时）：`shen = (yue + h) % 12`

> **注意方向**：生月自寅「顺行」（`+`）；命宫之生时「逆行」（`-`）；身宫之生时「顺行」（`+`）。
> **自检锚点**：正月（寅）子时生人 → 命宫在寅、身宫在寅；正月丑时生 → 命宫在丑（寅逆数至丑）、身宫在卯（寅顺数至卯）。符合通行排盘。

### 1.3 十二宫顺排顺序（自命宫起）

顺序固定，**盘上按「逆时针」**（地支柱从命宫起逆排），依次为：

`命宫 → 兄弟 → 夫妻 → 子女 → 财帛 → 疾厄 → 迁移 → 仆役（交友） → 官禄 → 田宅 → 福德 → 父母`

即：第 1 宫命宫，其后各宫按此序一格一格排（逆行）。`仆役` 亦即 `交友`（古称仆役，今多称交友/奴仆）。此顺序有版本记「福德→父母→命」循环，但十二宫定名与序号无分歧。

> 十二宫意义补充：财帛=疾厄之「财」，官禄=事业，田宅=房产家业，福德=精神享受。安命之后，命宫由此顺序反向布出其余十一宫。

## 4. 紫微星定位表（生日 × 五行局 → 宫位）

> ⚠️ **此项为最高风险项，如实声明**：本节给出**标准安星法**与**方向约定**，但**逐格（30 日 × 5 局）数值我未能与 iztro 源码逐格比对**（因网络隔离无法读取 `src/astro/star.ts` 与 `py-iztro` 源码）。**为避免编造，不在此列出一份可能失真的 30×5 静态表**；给出可靠方法与落地建议，**最终数值以 iztro/py-iztro 输出为准**。

### 4.1 原理（安星法）

紫微星是唯一一颗**其位置只由「生日」与「五行局」两个量决定**的十四主星（与生月、生时、年干均无关）。给定五行局数 `n`（水2/木3/金4/土5/火6）与生日 `d`（1–30），即可推出紫微星所在的地支宫。

### 4.2 标准方法（全书/中州派口径）

经典口诀（安十四主星之首）：

> 「紫微逆去天机星，隔一阳武天同临，又隔二位廉贞地，空三复见紫微星。」（紫微系）
> 安紫微星本体：**以「局数」与「生日」配合，自寅宫起，数生日之日数，再依「局数」进/退**。

具体推演（主流软件 iztro 同源逻辑，方向约定如下）：
- **局数 `n`**：水二=2、木三=3、金四=4、土五=5、火六=6。
- **生日 `d`**：农历初一到三十（1–30）。
- **方向**：主流为「**以寅（或特定宫）为起点，按局数顺行/逆行至生日**」——不同典籍对「顺数/逆数」与「起点是否为寅」存在口径差异（见第 4.4 争议）。**主流（iztro、王亭之、全书体系）的结果一致性以 iztro 为准。**

### 4.3 落地建议（推荐，非编造）

**直接用权威库算紫微**，而不是手工维护 30×5 表：

```python

#   pip install iztro? —— 以实际包名为准；参照 https://github.com/x-haose/py-iztro

# 取 result 中 紫微星 所在宫位即可。

# 方式二（x-iztro，Rust+Python，与 iztro v2.5.8 逐字段对齐，716314 黄金用例）
#   https://github.com/x-haose/x-iztro
```

若需**离线硬编码表**，请从 `py-iztro` / `x-iztro` 源码中导出其 `get_majestic_star`（紫微星）查表逻辑，经**黄金用例回归**后再落地。**切勿手推一张未经核验的 30×5 表。**

### 4.4 口径分歧（本项争议）

1. **起点**：主流「自寅宫起数」，少数自「子/卯」异。
2. **顺逆**：紫微星定位存在「阳男阴女顺/阴男阳女逆」之歧义——注意**紫微星的安法本身不分阴阳男女**（那是大限/小限的规则）；紫微星定位**只随局数与生日**。此点请以 iztro 输出为准。
3. **与天府的关系（可靠锚点）**：**紫微与天府恒以「寅—申」线为轴对称**（见第 6 节），这一对称关系是**跨派别一致**的，可用来反推验证紫微表。

## 5. 紫微星系 6 星安法（相对紫微）

**方向：紫微系由紫微起「逆行（逆时针）」。** 口诀：

> 「紫微逆去天机星，隔一阳武天同临，又隔二位廉贞地，空三复见紫微星。」

| 星名 | 相对紫微（逆行/逆时针偏移） | 间隔说明 |
|------|----------------------------|----------|
| 紫微 | 0（本位） | 起点 |
| 天机 | 逆 1 宫 | 紧邻（「逆去」） |
| 太阳 | 逆 3 宫 | 天机隔一（中间空 1 宫） |
| 武曲 | 逆 4 宫 | 太阳隔一（中间空 1 宫） |
| 天同 | 逆 5 宫 | 与武曲紧邻（「天同临」） |
| 廉贞 | 逆 8 宫 | 天同隔二（中间空 2 宫） |

> **⚠️ 修正附注（x_iztro 0.4.0 实测，即 iztro v2.5.8 权威输出）**：
> 原表「武曲逆5、天同逆7、廉贞逆10」是把口诀「隔一阳武天同临」误读成逐星隔一。
> 正确断句：天机隔一见太阳、太阳隔一见武曲、**武曲与天同紧邻（临）**、
> 天同隔二见廉贞、廉贞空三复见紫微。实测「紫微在寅」盘：
> 紫微寅、天机丑、太阳亥、武曲戌、天同酉、廉贞午——与口诀逐字吻合。

**Python 落地**（`idx` 为地支索引 0=子、1=丑、2=寅…11=亥）：

```python
BR = ["子","丑","寅","卯","辰","巳","午","未","申","酉","戌","亥"]
ziwei_off = {"紫微":0,"天机":1,"太阳":3,"武曲":4,"天同":5,"廉贞":8}
def ziwei_system(zw_idx):            # zw_idx = 紫微星地支索引
    return {s: BR[(zw_idx - off) % 12] for s, off in ziwei_off.items()}
```

> 复核示例（紫微在寅，经引擎实测验证）：`紫微=寅，天机=丑，太阳=亥，武曲=戌，天同=酉，廉贞=午`。

### 6.1 第 1 键关系：天府 = 紫微的「寅申轴对称」

> **⚠️ 修正附注（依据 x_iztro 0.4.0 实测，即 iztro v2.5.8 移植的权威输出）**：
> 下表原列「紫微在寅→天府在申」（索引和 ≡ 10）有误——那是「对宫（180°）映射」。
> 正确的寅申线**镜面反射**为：**天府 = (4 − 紫微索引) mod 12**（索引和 ≡ 4），
> 即 卯↔丑、辰↔子、巳↔亥、午↔戌、未↔酉 成对，而 **寅→寅、申→申 为不动点
> ——紫微在寅或申时紫府同宫**（经典「紫府同宫」格）。
> 实测五例：紫微丑↔天府卯、亥↔巳、辰↔子、酉↔未、午↔戌、申↔申 全部满足和≡4。

**紫微与天府关于「寅—申」连线镜面对称（修正后的正确关系）：**

| 紫微在 | 天府在 | 紫微在 | 天府在 |

### 9.1 庚年四化两派（重要）

- **主流派（天同化忌，`庚阳武阴同`）**：中州派（王亭之）、绝大多数现代排盘软件（含 iztro、派别软件）、以及「贪狼化忌/庚乾……」之外的通行口径采用。原因：中州派认为「四化须依星曜性质，天同有化忌之性」。

- **全书派（天相化忌，`庚阳武阴相`）**：《紫微斗数全书》古法以「天相化忌」——认为庚年天相化忌（天相为「印星」）。

## 10. 大限、小限、流年起法

### 10.1 大限（big limit，10 年一限）

- **起点**：命宫。
- **起点岁数**：由**五行局定**——水二局 2 岁、木三局 3 岁、金四局 4 岁、土五局 5 岁、火六局 6 岁（即「局数 = 命宫大限的起始岁数」/「命宫管几岁到几岁」）。
- **方向**：**阳男阴女顺行**（顺时针），**阴男阳女逆行**（逆时针）。
- **间隔**：每宫 10 年。

> 例：阳男、水二局（2 岁起）、命宫在寅 → 命宫大限 2–11 岁，次宫（卯）12–21 岁，依此类推（男命顺行）。阴女亦顺行；阴男阳女则逆行。

（阴阳判定：年干为甲丙戊庚壬为阳，乙丁己辛癸为阴；以此为「阳男/阴男/阳女/阴女」。）

### 10.2 小限（yearly mini-limit，一年一宫）

- **男命**：自「辰」宫起「子年」，顺行，一岁一宫。
- **女命**：自「戌」宫起「子年」，逆行，一岁一宫。
- 每年换一宫（以虚岁计）。

```python
def xiaoxian(gender, year_sheng, age):   # age 用虚岁，year_sheng 为生年支序(0=子)
    start = 2 if gender=='男' else 8     # 男辰=2, 女戌=8
    step = 1 if gender=='男' else -1
    return BR[(start + step*(age - 1)) % 12]
```

### 10.3 流年（太岁/流宫）

- **流年命宫** = 流年地支所在宫（流年太岁宫）。如流年为子年，则子宫为流年命宫。
- **流年十二宫**：自流年命宫起，依十二宫顺序排；方向与「男顺女逆」（或依阴阳）类同——主流以「**阳男阴女顺行、阴男阳女逆行**」定流年宫位走向。

```python
def liunian_gong(year_branch):  return BR[BR.index(year_branch)]   # 流年命宫=流年支宫
```

> 注：实际排盘常以「大限」（十年）为框架、流岁（太岁）与流年命宫叠加，具体软件实现略有差异。

## 11. 争议清单汇总（每条标注主流做法）

| # | 争议点 | 主流做法 | 对立做法 / 说明 |
|---|--------|----------|-----------------|
| 1 | **闰月安盘** | **闰月「作当月的下半月」并入当月，不单独作一月**（主流以「闰月前半月归本月、后半月归下月」或整体当月）。iztro 等软件默认**采用「当作本月」并入**结合精确交节。 | 部分古法「闰月以后半月作下月」，少数「闰月单独作一月」。 |
| 2 | **早晚子时** | 主流（iztro/软件）：**子时 23:00–01:00 均作当日**；但「早子时（23–24）与晚子时（0–1）」的**日期归属**有分歧：多数采「**子正（24点）换日**」——即 23–24 点为「当日深夜子」，0–1 点为「次日早子」，以子时换日为界。**主流：晚子时（23点后）是否算次日、早子时（0点）是否算当日，各处略异**，请以 iztro 的 `isLeapMonth/子时` 规则为准。 | 少数流派不分子时，23点起即算次日。 |
| 3 | **虚岁实岁** | 紫微斗数以**虚岁**计岁（大限/小限/流年之「岁」），出生即 1 岁。 | 实岁派系（极少数）。**主流虚岁**。 |
| 4 | **庚年四化** | **天同化忌**（中州派/iztro/现代主流）。 | 《紫微斗数全书》古法作「天相化忌」。 |
| 5 | **火铃安星** | **三合起宫 + 自该宫起子时顺数生时**（iztro/主流）。 | 纯按年支三合固定宫位（不数生时）；或起宫表、顺逆方向有版本差异。 |
| 6 | **紫微星定位顺逆** | 紫微星定位**只随局数与生日**，不分男女阴阳；起点多为「自寅起」，方向以 iztro 输出为准。 | 部分典籍混入「阳女/阴男」顺逆，属误用（那属大限规则）。 |
| 7 | **月令/交节** | 主流（iztro）以**节气（精确交节时刻）**定月份干支，而非农历初一定月。 | 古法以农历月。iztro 采节气。 |
| 8 | **闰月「当作当月/作下月/十五分界」** | 主流：**并入当月**（精确处理见 iztro 源码 `isLeapMonth`）。 | 「闰月十五以前作当月、十五以后作下月」亦有人用。 |
