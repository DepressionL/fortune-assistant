# 八字神煞 核验表（硬编码表）

> 用途：为 fortune-assistant 提供八字「神煞」判定所用的硬编码表（每一条给出：口诀 / 索引依据 / 判定规则 / 出处）。
> 说明：本文件核验核心神煞公式，出处以《三命通会》《渊海子平》（维基文库公开文本）为主，少数引《协纪辨方书》/《玉匣记》传统；每个表后附来源 URL。凡主流有分歧处并列标注。任何本文件未能找到可靠古籍出处的条目，均明确写「未找到可靠出处」，不臆造。
> 文档格式与 `research/liuyao_tables.md`、`research/ziwei_tables.md` 一致。
> 对应配置项：`fortune/config.py` 的 `shensha_base`（`"day"`=子平日干/日支查，主流默认；`"year"`=古法年干/年支查）。

---

## 0. 索引基准约定（重要，先读）

神煞按「查索引」分两类，且分「年上起」与「日上起」两派：

| 类别 | 所用轴 | 用途 |
|---|---|---|
| **干查**（用天干） | 天乙贵人、太极贵人、文昌贵人、禄神、羊刃（阳干） | 查日干或年干（主用日干） |
| **支查**（用地支） | 驿马、桃花/咸池、华盖、将星、劫煞、灾煞、孤辰、寡宿、红鸾、天喜 | 查日支或年支（主用日支） |
| **月支查**（月令） | 天德、月德 | 查出生月令（节气月之地支），不用日/年 |
| **柱查**（六十甲子） | 空亡/旬空 | 以日柱为准（六爻以日辰为准，同一张表） |

> **古法（禄命）多以年干/年支起；子平法多以日干/日支起**。程序统一用 `config.shensha_base` 决定：`"day"`（默认，子平主流）用日干/日支，`"year"` 用年干/年支。下表「索引依据」列会标出该神煞取干还是支，以及推荐基准。

> ⚠️ 各神煞的「起法」几乎都有古籍正文（本文件按正文核验）；但**「子平以日干/日支、古法以年干/年支」这一大框架属于后世流派习惯**，古籍中并非一刀切。程序做成可配置即符合实际。

## 1. 天乙贵人（宫神之首，两版本并列）

**口诀**
> 甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，六辛逢马虎。

**版本一（主流，用于排盘／《渊海子平》、《三命通会》通行本）**

| 日干/年干 | 贵人地支 | 地支（生肖） |
|---|---|---|
| 甲、戊、庚 | 丑、未 | 牛、羊 |
| 乙、己 | 子、申 | 鼠、猴 |
| 丙、丁 | 酉、亥 | 鸡、猪 |
| 壬、癸 | 卯、巳 | 兔、蛇 |
| 辛 | 午、寅 | 马、虎 |

**版本二（另一传本，仅「庚」归属不同）**
> 「……壬癸兔蛇藏，**庚辛**逢虎马。」

即把口诀末句「六辛逢马虎」改为「庚辛逢虎马」，使：甲、戊 → 丑、未；**庚、辛 → 寅、午**（庚与辛同位）。差异只在「庚」是随甲戊（丑未）还是随辛（寅午）。

- 判定规则：取日干（子平）或年干（古法），对照上表，柱中地支见其贵人地支即为带此煞。
- 索引依据：**干查**（日干/年干）。`config.shensha_base` 决定用哪个。
- 出处：
  - 《三命通会·卷三·论天乙贵人》（版本一：甲戊庚牛羊、乙己子申、丙丁酉亥、壬癸卯巳、六辛午寅，正文明确）https://zh.wikisource.org/wiki/三命通會/卷三
  - 《渊海子平》「日贵」节（言「甲戊兼牛羊之类」）https://zh.wikisource.org/wiki/淵海子平
- 版本差异标注：版本一为主流（多教教材、排盘软件默认）；版本二见部分通书/个别传本。**「庚→寅午」这一异说到底出自哪部古籍，尚难严格定论（属天乙贵人考证公案），故此处对版本二出处标注为「另有传本，具体古籍待考」。**

- 判定规则：取日干（子平）/年干（古法），柱中见上表地支即为带此煞。

- 出处：主流口诀（近世通行）；《三命通会·卷三》另给出**一套不同的「文昌贵」**：「甲乙蛇口乙猪头，丙狗丁龙戊向猴；己午庚寅辛未贵，六壬卯位癸逢牛。」（即甲→巳、乙→亥、丙→戌、丁→辰、戊→申、己→午、庚→寅、辛→未、壬→卯、癸→丑）。两套差异大，**主流子平排盘多取「甲乙巳午报君知」这套**。https://zh.wikisource.org/wiki/三命通會/卷三

## 4. 学堂 / 词馆（可选）

**口诀/定义**
> 学堂者，如人读书之在学堂；词馆者，如今官翰林。长生乃学堂之正位，临官乃词馆之正位。

即：**学堂＝纳音五行之长生位；词馆＝纳音五行之临官位**。

| 五行 | 长生(＝学堂) | 临官(＝词馆) |
|---|---|---|
| 金 | 巳 | 申 |
| 水、土 | 申 | 亥 |
| 木 | 亥 | 寅 |
| 火 | 寅 | 巳 |

- 判定规则：按柱（常以年柱/日柱纳音五行）长生位为学堂、临官位为词馆；也有人按日干纳音论。术语体系中另有「官贵长生之位为学堂、官贵临官之位为词馆」「学堂会禄」「学堂会食」等变体。
- 索引依据：**纳音五行**（非单纯干/支），各家起法不一。
- 出处：《三命通会·卷三·论学堂词馆》https://zh.wikisource.org/wiki/三命通會/卷三
- ⚠️ 分歧/可选：学堂词馆起法在古籍与今人体系中并不统一（纳音长生/临官、长生会禄、或与文昌关联等），**本项列入「可选」；若程序要硬编码，建议按「纳音长生=学堂、纳音临官=词馆」这一《三命通会》主定义，其余不作默认。**

## 6. 羊刃（阳刃；阴干分歧标注）

**口诀/定义**
> 羊刃者，禄前一位是也。子平以五阳干有刃：甲刃在卯、丙戊刃在午、庚刃在酉、壬刃在子；乙丁己辛癸五阴干无刃。

| 阳干 | 禄 | 刃（禄前一位） |
|---|---|---|
| 甲 | 寅 | 卯 |
| 丙 | 巳 | 午 |
| 戊 | 巳 | 午 |
| 庚 | 申 | 酉 |
| 壬 | 亥 | 子 |

- 判定规则：羊刃 = 日干（/年干）禄地之前一位（临官前一位＝帝旺位，仅阳干论刃）。
- 索引依据：**干查**（阳干）。
- **阴干 (乙丁己辛癸) 的分歧**：
  - 主流子平（《三命通会》《渊海子平》）：**阴干无刃**，阴干见「伤官」与羊刃同祸，不单列阴刃。三命通会正文原话：「子平以甲丙戊庚壬五阳干有刃，乙丁巳辛癸五阴干无刃，惟见伤官。」
  - 少数派/别派：认为阴干亦有「刃」（一说阴刃在帝旺位：乙→寅、丁→巳、己→巳、辛→申、癸→亥；一说按「羊刃乃劫财」阴干见劫财即刃）。**此为主流之外的分歧，程序宜默认「阳干论刃、阴干不论」，并做成开关。**
- 出处：《三命通会·卷三·论羊刃》https://zh.wikisource.org/wiki/三命通會/卷三 ；《渊海子平·论阳刃》https://zh.wikisource.org/wiki/淵海子平
- 注：古文献里「阳刃/羊刃」「羊刃煞」字面与含义有混用（有专指「阳干刃」者，也有泛指劫财者），本表按「羊刃＝阳干禄前一位」这一主流定义。

## 13. 天德贵人

**口诀**
> 正丁二坤三壬四辛五乾六甲七癸八艮九丙十乙十一巽十二庚。

（坤=申、乾=亥、艮=寅、巽=巳，按「二十三山/后天八卦」方位换算为地支。）

| 月支(月令) | 天德（地支） | 口诀本位 |
|---|---|---|
| 寅（正月） | 丁 | 正丁 |
| 卯（二月） | 申 | 二坤 |
| 辰（三月） | 壬 | 三壬 |
| 巳（四月） | 辛 | 四辛 |
| 午（五月） | 亥 | 五乾 |
| 未（六月） | 甲 | 六甲 |
| 申（七月） | 癸 | 七癸 |
| 酉（八月） | 寅 | 八艮 |
| 戌（九月） | 丙 | 九丙 |
| 亥（十月） | 乙 | 十乙 |
| 子（十一月） | 巳 | 十一巽 |
| 丑（十二月） | 庚 | 十二庚 |

- **核验说明（月支 vs 月令）**：天德、月德均按**出生月令（节气月）的地支**查，即「正月＝立春后寅月、二月＝惊蛰后卯月……」等，而非农历月序。此处「月支」「月令」在八字里是同一概念（月令之地支），但务必与「农历月份序号」区分。—— 程序中应以**节气月支**为准。
- 判定规则：取出生月令地支（月支），对照上表见对应地支即为带天德。
- 索引依据：**月支（月令）查**。
- 出处：《三命通会·卷三·论天月德》https://zh.wikisource.org/wiki/三命通會/卷三 （正文述天德「散在十二佐宫甲庚丙壬乙辛丁癸乾坤艮巽」即此表）；另《协纪辨方书》卷亦载天德起例（择日通用），此处以《三命通会》为准。

## 14. 月德贵人

**口诀**
> 寅午戌月在丙，申子辰月在壬，亥卯未月在甲，巳酉丑月在庚。

| 月支(月令)三合局 | 月德天干 |
|---|---|
| 寅、午、戌（火局） | 丙 |
| 申、子、辰（水局） | 壬 |
| 亥、卯、未（木局） | 甲 |
| 巳、酉、丑（金局） | 庚 |

- 判定规则：取出生月令地支，看其属哪个三合局，对应天干即月德。
- 索引依据：**月支（月令）查**。
- 出处：《三命通会·卷三·论天月德》（正文逐局：「申子辰会酉出庚入垣于壬」「寅午戌会卯出甲入垣于丙」「巳酉丑会子出壬入垣于庚」，故月德为壬（申子辰）、甲（亥卯未）、丙（寅午戌）、庚（巳酉丑））https://zh.wikisource.org/wiki/三命通會/卷三
- ⚠️ 文本小异：《三命通会》此段小结写作「戊壬甲丙癸谓之月德」，其中「癸」与正文逐局得出的「庚」不一致（应为庚/癸之讹）。**主流起法取「丙壬甲庚」（如上表），不建议采用「癸」。** 程序以「丙壬甲庚」为准。

## 15. 红鸾 / 天喜

**口诀**
> 红鸾：子年卯上起，逆数至亥年。（即从卯宫起，子年见卯，逐年逆推。）天喜：红鸾之对冲。

**红鸾（年支查）**

| 年支 | 红鸾 |
|---|---|
| 子 | 卯 |
| 丑 | 寅 |
| 寅 | 丑 |
| 卯 | 子 |
| 辰 | 亥 |
| 巳 | 戌 |
| 午 | 酉 |
| 未 | 申 |
| 申 | 未 |
| 酉 | 午 |
| 戌 | 巳 |
| 亥 | 辰 |

**天喜 = 红鸾对冲（年支查）**

| 年支 | 天喜 |
|---|---|
| 子 | 酉 |
| 丑 | 申 |
| 寅 | 未 |
| 卯 | 午 |
| 辰 | 巳 |
| 巳 | 辰 |
| 午 | 卯 |
| 未 | 寅 |
| 申 | 丑 |
| 酉 | 子 |
| 戌 | 亥 |
| 亥 | 戌 |

- **核验说明**：红鸾起法「子年卯、逆数」→ 子->卯、丑->寅、寅->丑、卯->子、辰->亥、巳->戌、午->酉、未->申、申->未、酉->午、戌->巳、亥->辰，与上表一致；天喜＝红鸾对冲（如子年红鸾卯，卯冲酉→天喜酉），上表已核验一致。
- 判定规则：取年支，按「红鸾/天喜」两表分别对照。
- 索引依据：**年支查**（红鸾天喜以年支起，流派较统一；少有人说以日支起，主流为年支）。
- 出处：
  - 年支红鸾天喜为**择日/命理传统（《玉匣记》通书系统为主）**，可在通书与命理入门见广泛引用；本文件核验其对照关系（逆数 + 对冲）逻辑自洽。
  - 《三命通会·卷三·论天月德》另记一种**四时天喜**（「天喜神，春戊、夏丑、秋辰、冬未」），与年支查法不同，属另一体系，勿混淆。https://zh.wikisource.org/wiki/三命通會/卷三
- ⚠️ 出处说明：年支红鸾/天喜**未能从《三命通会》/《渊海子平》直接找到等价原文**（《三命通会》只有四时天喜），其本源于《玉匣记》等择日书；《玉匣记》公开文本本文件未取得完整可核验版本。**故「年支红鸾/天喜」这一条，从正规命理古籍角度标注为：主流命理/择日通行表，古籍正文出处待考（以《玉匣记》系统为准）；本文件按通行对照表收录，并已核验其内部关系成立。**

## 16. 孤辰 / 寡宿

**口诀/定义**
> 亥子丑（冬）进前一辰见寅为孤，退后一辰见戌为寡；其余三方依此推。（按四季三支分方取「前后一辰」）

| 年支/日支所属季 | 孤辰 | 寡宿 |
|---|---|---|
| 亥、子、丑（冬，北方） | 寅 | 戌 |
| 寅、卯、辰（春，东方） | 巳 | 丑 |
| 巳、午、未（夏，南方） | 申 | 辰 |
| 申、酉、戌（秋，西方） | 亥 | 未 |

- 判定规则：取年支（古法）/日支（子平），看其属哪个季（三支组），「前一位」为孤辰、「后一位」为寡宿。
- 索引依据：**支查**（年支/日支，按四季分方）。
- 出处：《三命通会·卷三·论孤辰寡宿》（「如亥子丑逐方三位，进前一辰见寅为孤，退后一辰见戌为寡。其余三方皆依此推。」）https://zh.wikisource.org/wiki/三命通會/卷三

## 17. 空亡 / 旬空（六十甲子旬空，与六爻通用）

**口诀/定义**
> 甲旬尽处曰空亡。十干遁至旬尾，所余两支即空亡（有支而无干）。

以六十甲子分六旬，每旬（十日）有二支为空亡：

| 旬 | 干支范围（10 组） | 空亡地支 |
|---|---|---|
| 甲子旬 | 甲子…癸酉 | 戌、亥 |
| 甲戌旬 | 甲戌…癸未 | 申、酉 |
| 甲申旬 | 甲申…癸巳 | 午、未 |
| 甲午旬 | 甲午…癸卯 | 辰、巳 |
| 甲辰旬 | 甲辰…癸丑 | 寅、卯 |
| 甲寅旬 | 甲寅…癸亥 | 子、丑 |

- 判定规则：取日柱（子平）/年柱（古法），看其干支属哪一旬，对应空亡地支即旬空（六爻以日辰为主，用同一张表）。
- 索引依据：**柱查（六十甲子旬）**。
- 记忆法：每旬旬首（甲X）从旬首支起顺数 10 支配完，所余之 2 支即空亡（如甲子旬：子丑寅卯辰巳午未申酉 10 支，余戌亥为空亡）。空亡位可由「旬首甲 与 当前干支的差数」计算，程序可直接用公式。
- 出处：《三命通会·卷三·论空亡》（「如甲子遁至酉而十干足，所以无戌亥」「甲寅旬、壬癸落空亡；甲辰旬，甲乙；甲申旬，丙丁；甲戌旬，庚辛」）https://zh.wikisource.org/wiki/三命通會/卷三
- 与六爻一致：**与 `research/liuyao_tables.md` §5「旬空表（六甲旬空）」完全相同**（同属六十甲子旬空），按六爻用法亦以日辰为该旬之「旬首」判定，两张表必须一致。
